# 从报告到可复用模板的操作与归属

日期：2026-09-13。

1. 在整本小说分析中选择已保存运行并读取报告。综合结论和专题已在本机保存，Markdown 导出不是保留分析的前提。
2. 点击“从报告生成模板”，填写名称和维度，选择连接与本次转换预算。“预览转换计划”可选，不产生模型请求。
3. 点击“生成新模板草案”。任务、输入和结果自动保存，完成后模板库出现独立草案；生成期间可继续编辑其他模板。
4. 预览具体要求、推断/建议、适用条件、待处理项和来源 S 编号。F 编号对应原报告证据。长期规则中的推断/建议没有自动写入硬规则原文。
5. 点击“打开生成草案”。若已有未保存编辑，先保存或放弃当前编辑；新草案已经独立落盘，无须重新生成。
6. 编辑后“保存新版本”。作品模板选择器刷新可选版本，默认只勾选有内容的字段，再预览差异并采用。各书保存独立内容快照。

历史转换按原报告列出并可继续加载。继续所选任务使用保存的模型配置，仅允许增加总预算；调整模型或单次容量新建转换。单纯补保存不会再次请求模型；失败或未知费用需复核，所有已计/预留仍留在同一预算。

关闭先排空模型与本地保存，页面隐藏不销毁根任务。模板已保存而登记失败时，错误文案明确模板已存在；恢复按同一身份核对，不创建副本或覆盖作者修改。并发目标来源冲突会阻止写入。
