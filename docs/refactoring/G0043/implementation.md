# G0043 实施说明

日期：2026-09-13。

报告阅读器组合独立 ReportTemplatePanel；完整报告可展开转换，部分报告说明缺项。面板编辑新任务参数，根级 ReportTemplateActivity 持有执行和交付，隐藏或切换报告不取消运行。历史和来源按当前报告分组，旧异步加载不能覆盖新选择；重开时读取费用和失败候选，不自动调用模型。

ReportTemplateDeliveryService 将候选变成四类创作规范并保存新草案。长期规则只自动写入明确支持项，推断和建议保留在预览。目标身份在任务创建时确定，模板首次插入失败后核对来源凭据；重复恢复返回已有草案，允许它已被用户修改。模板成功而任务登记失败时保留可恢复标记。

共享模板工具负责打开和编辑；未保存草案受原有保护。生成后刷新列表，保存新版本通知作品选择器刷新，作品内容仍只在明确采用时变化。空字段默认不选，主动采用空字段会在差异预览说明清空语义。来源摘要随模板展示。

分析运行列表接入超过 100 条后的继续加载，进度显示真实检查点时间和已保存数量。操作见[报告转模板流程](report-to-template-workflow.md)。
