# G0006 实施方案

基线 G0005 `dba8c5c`。实现 G0006-01 至 G0006-04，对应 FR-07 与 A05/A06/A07/A10 的本地部分。

## 设计与职责

`Domain/WritingRules.cs` 保存稳定规则身份、版本、原文、解释、来源、强度、范围、例外和启停。
`WritingRuleSet.Commit` 产生新规则版本及规则集版本；`RuleEvaluation` 纯计算适用规则、检查摘要、确定性命中和冲突。
检测不依赖模型、数据库或 UI，也不执行输入中的任意代码。字符串规范化保留原始 UTF-16 索引。

`MainDocument.Rules.cs` 将规则表单草案、已提交版本和检查展示分开。本书的 RuleEditor 进入原有可靠保存会话，
但只有“保存规则版本”改变执行规则。未提交草案阻止切换，作者可明确放弃。跨作品切换与重开恢复本书表单。
检查计算在后台完成，提交前复核当前正文/规则/运行；相同后台保存通知不会重复填充命中列表或清空选中项。

## 产品行为

“本书规范与模板”内提供规则编辑和本地检查。禁止文本、必须包含、语义指导分别表达；UI 枚举显示中文。
可选忽略标点和空白；禁止规则的例外仅豁免被例外完整覆盖的那次命中。
命中保留正文原文与位置，作者可选中正文对应范围；检测从不改写手写内容。

语义指导和原有 Profile.Rules 只显示待检查，不能以没有确定性命中推断语义通过。
检查记录绑定正文哈希、启用规则内容/版本、原规则文本和运行身份。正文/规则/运行变化后显示过期。

## 持久化与兼容

作品 schema 5 增加规则集、规则表单和本地检查记录；旧 1–4 经 SQLite 一致性备份后迁移。
恢复文件写格式 5，兼容读取 1–5。复制成新书时映射卷范围身份并清空本地检查，避免旧位置证明新书。
旧运行规则不会自动扩大为全书规则；新的运行身份不匹配旧范围。

专项：[规则与检测契约](writing-rule-contract.md)。模型请求装配、语义检测和有限返工由 G0009/G0011 接入。
