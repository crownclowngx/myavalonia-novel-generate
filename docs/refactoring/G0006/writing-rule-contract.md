# G0006 长期规则与本地检测契约

## 状态与范围

规则表单草案、保存的规则版本、Enabled 和本地检查结果是不同状态。保存草案不自动启用新内容；
保存规则版本提升本书规则集 Version。没有模型请求时不显示“已用于生成”。

| 范围 | 生效边界 |
| --- | --- |
| 通用快照 | 明确复制到本书的通用要求，不订阅一个可变全局对象 |
| 本书 | 本书所有章节 |
| 本卷 | 保存时选定章所属卷；编辑旧规则保留其原卷身份 |
| 本次运行 | 当前实际 ActiveRunId；没有活动运行时不允许新建该范围，结束后仍可停用旧规则 |

局部批注不会自动变成全书禁令。当前没有语义理解引擎，互斥冲突仅检测可确定的硬性文本要求与禁止关系，
不是通用逻辑求解器。不同范围先筛选适用规则，再检查冲突。

## 文本语义

- 默认按 Unicode 原文精确、区分大小写匹配，不运行正则。
- “忽略分隔符”移除 char.IsPunctuation / char.IsWhiteSpace，包括标点、空格与换行；可跨句命中，由作者明确选择。
- 位置为零起点 UTF-16 偏移，UI 显示为一起点；与 Avalonia TextBox 选择位置一致。证据直接从原文截取。
- 禁止文本允许重叠命中。例外按相同规范化方式匹配，必须完整覆盖命中区间；同章另一处命中不因此豁免。
- 必须包含未出现时位置为 -1、长度为 0，只提示缺失，不伪造定位。其例外列表必须为空。
- 语义指导不进行本地“通过”判定；本书原有长期规则原文也保留为语义待检。

最多 2000 条已保存规则；禁止文本长度最多 2000 字符，规则原文最多 10000，例外每规则最多 50 条。
命中、展开例外或冲突达到执行容量上限时标为未完成，不能用于证明通过；界面提示先调整范围再检查。

## 证据与失效

LocalRuleCheck 保存章 ID、运行 ID、正文 Hash、规则 Stamp、时间、具体证据、冲突与语义待检数。
Stamp 包含规则集版本、适用启用规则及 Profile.Rules；禁用、编辑和原规则文本变化都会使旧检查过期。
检查不会把 ChapterRevision.Check 改成 AI 通过，也不会替代人工定稿。

检查针对编辑稿；后续导出选定工作/正式稿时须传入该版本实际正文重新检查，不能借用当前编辑稿记录。
本文只规定本地证据，生成请求和语义结果必须在后续阶段与同一规则版本关联。

## 回归场景

中文跨标点/换行、表情前缀位置、局部例外、必须包含、建议与语义指导、卷/运行范围、旧运行停用、
正文/规则变化失效、两书卷身份映射、未提交草案保护、重启、命中上限与原生编辑器选区均已覆盖。
长篇性能和更复杂冲突不在本阶段宣称完成；没有引入 AIFLOW、Windows CI 或发行检查。
