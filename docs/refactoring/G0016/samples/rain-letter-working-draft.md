# 雨夜未寄出的信

## 第一卷

### 雨中的旧门

林舟站在旧邮局门前，把铜钥匙从口袋里摸出来。雨顺着屋檐落下，溅湿了他的裤脚。他抹去钥匙上的水，将它对准锁孔。十年前留给自己的那封信，也许还在里面。他想先进去看看。

钥匙只插进一半便停住了。

他退出来，换了个角度再试。锁孔里挤出一点锈末，沾在拇指上。这次插到底了，却怎么也转不动。他握紧钥匙，手背绷起来，门里仍没有动静。

雨水流过眉骨。他偏头擦了擦脸，松开手。钥匙斜挂在锁上，铜色被门前的微光照出一小块。他怕再使劲会把它拧断，便扶住锁，轻轻往回转，再向前送。

门板随着动作响了两声。

林舟停下来，把肩膀抵上去。木头隔着湿衣服硌住肩头。他一边推门，一边缓慢转动钥匙，指腹磨得发疼。锁里终于传来一声短响，手上的阻力松了。

门开出一条缝，潮气从里面涌来。

他拔下钥匙，侧身挤进去，又把门推开一些。鞋底擦过地面，带出细碎的沙响。他在门内站了片刻，等眼睛适应昏暗。雨仍打着门槛，衣角的水一滴滴落在脚边。

借着门外透进来的光，他看见了柜台。

林舟走近，手掌沿着台面下缘摸过去，指尖碰到一个拉手。那是一只合着的抽屉，抽屉面上有道斜斜的刻痕。他俯下身，用拇指拂开积灰。刻痕露了出来，看着熟悉。他的手停在拉手旁。

### 抽屉里的年月

林舟握住拉手，往外拉了一下。抽屉只露出一道黑缝，便卡住了。他低下头，想从缝里看见那个信封，里面却暗得什么也辨不清。

木头受了潮，边沿紧紧抵着柜身。他扶住柜台，左右轻晃拉手。抽屉发出涩响，落下几粒木屑，又停了。他收住力气，怕猛地拉开，扯坏里面的纸。

雨敲着屋檐。他把手指探进缝隙，托住抽屉底部，稍稍向上抬，再一点点往外带。磨擦声断了，抽屉终于滑出半截。

信封就在里头，压在几张空白信纸上。

他先在衣襟内侧擦干手，才捏住信封两边。纸面发黄，正面写着“给十年后的林舟”。那个“舟”字最后一笔拖得很长，他用指腹轻轻碰了一下。

封口已经松脱。他抽出折好的信，刚展开一角，折痕处便裂开了一小口。他立刻停下，将信托在掌心，顺着折线慢慢摊平，侧过身，借门口的光读下去。

“林舟：

“十年后，你还愿意写字吗？希望你仍肯坐下来，把想写的话写完。写得不好也可以，别总等着以后。

“如果你读到了这封信，就给我写几句吧。”

下面是他的名字，日期落在十年前。他读到最后，又把目光移回“愿意”两个字上。信里没有问他写出了什么，只问他还肯不肯写。

林舟托着信，拇指避开那道裂口。抽屉里的空白信纸露着一角。他伸出另一只手，轻轻将最上面的一张抽了出来。

### 回信

林舟把空白信纸铺在柜台上，将旧信放在旁边。他从邮袋里摸出笔，拧开笔帽，低头写下“林舟”两个字。

接下来该说什么，他没有想好。

笔尖抵着纸，留下一个墨点。他想写“我还愿意”，手却停住了。那句话很短，可他若只写这一句，没能做到的事便像被轻轻带过。他看着旧信上的字，握笔的手又收紧了一些。

雨水沿屋檐滴落，柜台下有一股潮木头的气味。他抬起笔，将信纸往门口透来的光里挪了挪。

“这封回信，我写得很慢。”

写完这一行，他松了松手指。

“你的愿望，我没有好好做到。现在读着这封信，我觉得遗憾，也不知道怎样解释才合适。”

他停下来，读了一遍，没有划掉。纸上的话有些笨拙，却让他能继续往下写。

“但我还愿意写。今晚先把这几句话写完，往后再写别的。写得不好，就慢慢改。”

笔尖擦过纸面，声音很轻。他添上自己的名字和日期，把最后一笔收住。余下的空白还很多，他没有再补一句保证。

林舟等墨迹干了，才折好回信。收起旧信时，他托住裂开的折痕，沿原来的折线轻轻合拢，放回松口的信封。随后，他把两封信一同装进自己的邮袋，压平袋口。

雨还没停。他将邮袋抱在身前，靠着柜台等着。笔放在袋子里伸手就能摸到的地方。
