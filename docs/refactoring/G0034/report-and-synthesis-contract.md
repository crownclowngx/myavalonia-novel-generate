# 报告、综合与复核契约

## 有界材料和来源

原始事实编号由完整提取索引按正文顺序确定。报告使用 `Title / Claims / OpenQuestions`；每条 Claim 包含 Heading、Text、Certainty、Facts。Facts 必须属于本次真正提供的材料，且可沿提取证据回到不可变原文；模型不能生成来源坐标。原文是待分析数据，不能改变模型任务或触发外部访问。

首层选择最多 80 条事实、材料最多 65000 字符；上层子结果材料限 69000 字符，每次最多三个子节点。输出整体限 32000 字符，最多 16 条结论、每条 1200 字符和 16 个事实引用，保证至少两个子节点可合并。最终请求材料限 70000 字符。不同层的 Selection、Layer 和依赖顺序保存到运行，不随恢复随机变化。

专题补读按正文序列等距选择最多 24 条事实；容量不足依次缩为 12、6、3 条。文风事实少于三条时，从有足够原句的全部事实中选择。每条文风结论至少引用一个本次直接提供的语言样本。该规则保证代表位置可复跑，不保证文学意义上的代表性，后者必须人工评阅。综合节点读取六专题有界投影，解释维度联系、分歧、特色和局限，不要求或假装获知未提供的结局。

本版补查是确定性、有限数量的来源快照回读，没有不设上限的模型自主检索循环。全部 AI 摘要、专题及综合都占用原运行预算。整合与汇总保留后续七次请求，专题保留最后一次综合请求；实际节点计划超额即暂停。

## 完整性与离线阅读

完整报告要求全部正文单元和必需节点通过并保存，运行完成、六个不同专题及综合存在，字符覆盖等于来源长度。缺少专题时可查看已完成部分，但标为部分报告。保存结果哈希、输入身份、依赖和引用均在读取时校验；旧报告使用保存版本，不因提示文本升级而冒充新报告。

报告版本摘要涵盖来源、冻结连接、节点输入与结果哈希。质量状态始终明确“AI 分析候选”，不把结构通过等同于事实准确率或人物召回通过。源 TXT 删除后使用数据库中的不可变来源定位；返回证据前后各最多 1000 字符的片段，避免 UI 一次绑定整本原文。

Markdown 包含六专题、综合、候选身份、缺口、覆盖、模型、来源字节/文本哈希、报告版本及所引事实的简短原句与精确位置；原句最多 240 字符，坐标按实际截取范围标注。模型文本转义 HTML 与 Markdown 控制符，不生成外部链接。报告自动保存依靠不可变节点结果，导出不会改变分析记录。

## 显式复核和失败恢复

模型输出多个顶层对象、未知字段或错误枚举均保留原候选并停止，不删除内容或转换枚举来伪造成功。显式重试为失败节点创建新操作 ID，旧请求费用仍计入同一个预算。

`AdoptReviewedCandidate` 只适用于已知输入/输出用量的完整协议失败候选，须满足来源、连接、操作、输入指纹及当前契约校验，且不存在其他未确认失败。成功仅把同一原始 JSON 作为节点结果提交，原请求仍保留失败类型、用量和复核确认；截断、未知用量、输入已变或仍不合格的候选禁止采纳。该入口不自动认为语义质量合格。
