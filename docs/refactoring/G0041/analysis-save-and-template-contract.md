# 分析保存与报告转模板契约

日期：2026-09-13。版本：`report-template-v1`。

## 保存归属

原文在 reference-analysis.db，运行及已完成节点在 reference-runs.db，响应与费用在 model-requests.db；不重新保存第二份可编辑正式报告。转换在 report-template-conversions.db，模板仍在 catalog.db。转换删除外部 TXT 后使用冻结来源；每次进度读取不执行模型。

## 规范容量和来源

| 项目 | 上限 |
| --- | --- |
| 冻结结论 | 256 条，每条 2400 字符，最多 2 条/400 字符原文证据 |
| 规范维度 | 所选 World/Style/Methods/Rules，最多四项，每项只出现一次 |
| 每维度要求 | 16 条，每条正文 600 字符、适用条件 200 字符 |
| 每条要求引用 | 最多 4 个冻结结论编号；明确支持/推断至少一个，建议可无引用 |
| 每维度待处理项 | 8 条，每条 300 字符；没有规范时必须说明缺口 |
| 单个模型结果 | 80000 字符；额外字段、数字枚举和未知引用拒绝 |
| 执行计划 | 最多 64 个步骤；单份存储快照最多 800 万字符 |

Supported 仅引用明确来源；Inferred 不接受纯建议来源；Suggestion 不宣称原著事实。引用同时检查所选维度。长期规则中的推断/建议如何呈现、是否进入本书规则，由 G0042/G0043 按主计划实现。

## 并发和恢复

任务创建前分配固定目标模板身份。运行加文件独占租约；每次检查点以预期版本更新。来源、配置、步骤依赖及目标身份不可改写；预算只可显式增加，成功步骤和候选不可覆盖。最终模板保存之后的登记失败在后续阶段按相同身份补偿。

恢复文件位于 Recovery/TemplateConversions，与正常快照使用同一验证。数据库和恢复介质均不可写时不声称已保存；不承诺未落盘内容重启零丢失。未知数据库版本拒绝写入，不伪造或执行不存在的旧版迁移。

模板来源是可选、无密钥、无应用服务引用的领域快照。首次生成内容指纹不随作者后续编辑改变；复制到新机器仍保留出处摘要，详细原文定位依赖原来源库。
