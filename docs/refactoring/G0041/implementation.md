# G0041 实施说明

日期：2026-09-13。

分析运行的 `List` 新增有界 offset/limit，仍按插入顺序倒序读取，默认行为保留最近 100 条。既有接口实现和测试替身同步调整；页面继续加载在 G0043 接入。

新增报告来源、条目、规范候选和转换任务模型。来源材料与输出引用分开，固定来源版本、操作 ID、目标模板 ID；规范四维度只允许所选内容，明确支持不能由推断或建议冒充。契约共用容量常量，并返回具体字段路径。

独立转换库使用版本/应用标识、快照指纹、乐观更新及文件租约。成功步骤和候选不可覆盖，恢复文件先写临时文件并刷盘，再原子替换。已交付任务禁止后续写入；模型账本及模板库的补偿由 G0042/G0043 承接。

模板草案/版本新增可选来源，空来源不参与 JSON 输出，保持旧对象序列化及指纹语义。模板编辑保留来源，发布复制来源快照；现有导入导出、复制与恢复继续使用模板模型，不增加另一套模板格式。

具体边界见[保存与转换契约](analysis-save-and-template-contract.md)。
