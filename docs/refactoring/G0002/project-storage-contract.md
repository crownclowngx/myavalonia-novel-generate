# G0002 项目存储契约

## 文件与身份

作品由作者选择保存位置，扩展名 `.noveldb`。SQLite `application_id=0x4E4F564C`、`user_version=1`。
当前阶段只保存一个完整编辑聚合：`project(singleton, id, version, snapshot)`。snapshot 是 UTF-8 JSON，包含
作品、卷、章的稳定 GUID、标题、创意、提纲及正文。它是当前编辑状态，绝不表示定稿或 AI 已检查。
正文修订与记忆事务在 G0003 增加；现在不创建伪装已实现的历史表或迁移。

目录库位于 `%LOCALAPPDATA%/NovelGeneratePlugin/catalog.db`，仅存最近 30 项的查询结果（路径、书名、身份、
最后打开时间），不存正文或密钥。目录库出错可以直接选择作品文件；作品保存成功不能被目录异常否定。

路径使用 `Path.GetFullPath` 和不区分大小写比较；进程内同时检查项目 GUID。文件别名仍受书身份检查和
SQLite 版本比较保护。跨进程用同目录 `.writer.lock` 的系统独占共享锁，进程退出自动释放；空锁文件保留。
复制成独立作品必须重分配书卷章 ID；直接复制数据库保留书身份，同进程不能同时编辑两个这样的副本。

## 写入边界

- CreateNew 原子拒绝覆盖；建库成功后才登记最近项目。初始化失败只清理由本次创建的文件。
- Save 在同一 SQLite 事务中核对项目 ID 与预期版本，再更新完整快照并递增版本。
- 使用 WAL、同步 FULL、2 秒 SQLite 等待超时和关闭连接池；未使用网络或外部数据库服务。
- 未知 application_id、schema、非法 GUID、孤立章节和重复身份拒绝读取/写入，不盲目迁移。
- SQLite 普通备份、作者选定导出与模板迁移属于 G0007，不能直接复制正在写入的 WAL 主文件冒充备份。

## 恢复文件

恢复目录为 `%LOCALAPPDATA%/NovelGeneratePlugin/Recovery`。每个会话独立文件名，含格式版本、原路径、预期数据库版本、
编辑版本、时间及完整作品快照。先写临时文件、Flush(true)，再原子替换；正文恢复文件属于作者私有数据，不提交 Git。

恢复状态必须与当前编辑版本匹配。较早版本成功写入恢复，不代表保存期间新输入也有保护。重试失败时会读取并验证
现存同版本副本，不把已有保护误报为消失。主库写入成功后仅清除当前会话自己的恢复文件；其他历史副本保留。

UI 提供“恢复为新项目”，生成新书卷章身份，保留原库与原恢复文件。某个文件损坏、占用或无权读取时显示不可读条目，
其余正常副本仍可选择。自动保存失败不伪装成已保存；主库和恢复位置同时失败时保留内存并要求重试。

## 私有运行时资产

Microsoft.Data.Sqlite 10.0.10、SQLitePCLRaw.bundle_e_sqlite3 2.1.12 已锁定。私有声明包含托管 Core、bundle、
provider、原生 lib；不携带共享 SDK/Avalonia/DI。G0002 在开发暂存目录验证了 10 个资产，含
`runtimes/win-x64/native/e_sqlite3.dll`，并在独立 ALC 实际创建/读取中文项目。

这属于开发期存储依赖探针，不是发布门禁，不生成正式 ZIP，也不表示真实 Host 已验收。
