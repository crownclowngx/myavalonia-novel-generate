# G0015 实施方案

界面分为目录、正文、侧栏和底部状态。侧栏按创作、检查、设定、项目分组；各自滚动，正文不随设置区域滚出视野。
小于 1040 逻辑像素时切换正文/侧栏，不重建控件，保留选区和表单。布局状态归 View，不污染作品数据。
连接工具显示中文 Provider 名称，输出上限和推理强度分行，适应窄 Dock。

`NovelCommands` 只声明身份与文字。`MainDocument.Workbench` 把七项稳定身份映射到同一按钮命令，
真实 Host 负责活动 Document 路由；注册表不捕获实例或 IServiceProvider，不贡献新快捷键。
外部令牌链接到操作令牌，取消/暂停允许在异步命令进行中调用，且不覆盖正在执行的令牌。

审查修复：忙碌期间拒绝切章；生成提交只刷新仍选中的章；放弃和回退保留编辑摘要；
操作先登记完成任务，再发布 IsBusy 与状态通知，防止同步通知重入关闭时漏等刚启动的操作。
关闭清除命令订阅，显示端抛错不能阻断保存排空。

见 [交互命令契约](interaction-and-command-contract.md)、[UI 矩阵](ui-acceptance-matrix.md)、[结果](result.md)。
