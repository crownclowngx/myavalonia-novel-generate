# 工作区交互与命令契约

## 从空状态开始

填写书名/创意并创建 `.noveldb`，或打开已有作品。目录切章，正文自动保存；新增章和卷位于目录底部。
创作页包含章纲、单章候选与连续运行；检查页包含长期规则、修订、历史、影响和连续定稿；设定页管理规范、实体和本书连接；
项目页包含书名方向、选版导出、备份、最近项目和恢复副本。模板与连接 Tool 仍是共享目录，关闭/隐藏不替其他书修改设置。

正文底部区分工作/正式稿状态、任务状态和保存状态。停止原因完整换行，长提示可滚动；不能把“空闲”理解为“检查通过”。
窄窗用右上切换按钮打开侧栏；回正文保留选区和长文本。键盘 Tab 沿原生控件顺序移动，正文支持原生选择/复制，不新增全局快捷键。

## 七项 Workbench 命令

| 后缀 | 动作 | 边界 |
| --- | --- | --- |
| open | 打开小说项目 | 空闲时调用原生项目选择端口 |
| start | 开始连续创作 | 使用本书配置和侧栏预算 |
| pause | 当前章完成后暂停 | 仅活动连续运行有效 |
| cancel | 立即取消创作请求 | 取消本 Document 的规划/单章/连续任务 |
| generate | 生成并审校本章 | 同按钮用例及字数/修正上限 |
| finalize | 人工定稿本章 | 作者主动触发，使用当前工作修订 |
| export | 预览小说正文导出 | 预览所选版本与范围；确认和写文件在项目页完成 |

前缀为 `myavalonia.plugin.novel.generate.command.`。只对小说 Document 注册，其他文档活动时菜单隐藏。
选区改写属于局部命令，避免宿主调用时丢失用户选区语义。
异步命令返回真实完成任务，外部取消传给模型/选择器；本地提交若已开始则完整结束。业务错误保留界面信息，同时向 Host 返回失败。

## 生命周期

忙碌时拒绝切换章节与项目；关闭先取消并等待操作，再保存/恢复和释放租约。任务登记先于外部状态通知，保证重入关闭可等待。
两个 Document 使用不同 Scope；两个 Tool 按插件单例。隐藏 Tool 不结束共享任务，最终退出按已有 Shutdown 协议排空。
