# G0030 实施方案

日期：2026-09-12。对应 G0030-01–05。

`TxtSourceReader` 实现 `ITextSourceReader`，限制字节并严格解码；`NovelTextPartitioner` 只执行确定性分章/切块；`NovelImportService` 编排异步预览和快照保存。生产 DI 登记三个职责，UI 后续直接复用这些用例。

UTF-32 BOM 先于 UTF-16 判断；无 BOM 先尝试严格 UTF-8，再尝试 GB18030，并返回需要核对的预览提示。显式编码与 BOM 冲突时拒绝，损坏字节不替换。原文不规范化换行，标题可以缩短显示但对应原文保持完整。

中文数字、阿拉伯数字的章/回/节/卷等行及英文 Chapter 行作为分界；卷首说明、重复标题均保留。无标题时按连续片段处理。长章按目标长度后半段换行切分，必要时按完整代理对边界切开；上下文可跨章，正文归属不跨章。

预览阶段只读源文件；保存预览快照后，源文件移动或变化不会把作者已核对的内容换掉。取消在事务前生效；已经进入的来源导入事务完整提交或回滚。

专项规则见[来源与覆盖](source-and-coverage-contract.md)。`AnalysisProbe` 是显式离线开发工具，不进入普通测试或生产包；只接收调用者指定输入与全新输出目录，保存元数据及独立来源库。
