# 检查与局部修正矩阵

| 条件 | 当前行为 | 验证 |
| --- | --- | --- |
| 完整正文与四维报告通过 | Ready，允许原子工作稿提交 | 真实 SQLite 提交/重开/重复操作 |
| 正文截断 | 保留正文，不启动审校 | 故障模型与请求次数 |
| 报告截断/缺字段/伪造证据 | 不完成必要检查，不提交 | 结构契约、原文定位 |
| 完整 JSON 外围代码围栏 | 本地移除外围后完整校验，保留原始响应 | 正常围栏与截断围栏回归 |
| 硬规则与模型报告相反 | 本地硬失败优先 | 禁用词夹具 |
| 计划事实/未知身份/重复字段 | 阻止进入工作稿事实 | 类型化事实证据门禁 |
| 未完成检查或未保持章纲 | 待处理 | 四维与锁定标记回归 |
| 修正片段缺失/多次或重叠命中 | 拒绝猜测位置 | 唯一性与重叠匹配回归 |
| 修正超过 30% | 拒绝扩大为全篇改写 | 修改上限回归 |
| 修正后新事实疑点 | 完整复查仍失败，次数耗尽停止 | 四次请求夹具 |
| 取消后迟到完整结果 | 保留候选，不能审校或提交 | 可控异步模型 |
| 作者修改正文/规范 | 候选来源过期 | 提交前版本复核 |
| 提交中断 | 原正文和修订保持，候选可重试 | SQLite 触发器故障 |
| 保存中编辑书名/正文 | 字段合并，保留新输入，生成正文不倒退 | 阻塞存储并发夹具 |
| 状态通知异常 | 自动保存与关闭仍完成 | 抛错订阅者回归 |
| 较旧候选落盘 | SQL 序列门禁拒绝 | 重开内容校验 |
