# G0007 备份、恢复、模板交换与正文导出

## 文件提交

输出只写新文件；选择已存在路径时拒绝并保留原输出。临时文件与目标同目录，完整写入及 Flush 后才移动到目标，
最后的移动也禁止覆盖，防止检查目标路径后出现并发创建。

作品备份通过 SQLite BackupDatabase，包含已提交 WAL，不带入其他连接尚未提交的事务。
临时备份完成结构验证和必要迁移，再显式完成 WAL 检查点并 Flush，最后发布单文件。
备份和恢复均保留作品身份；恢复升级只作用于临时副本，原始备份保持原格式。
目标 `.writer.lock` 防止写入正被其他窗口持有的项目路径；源作品可继续持有写会话。

恢复入口生成新文件，不直接覆盖正在编辑的作品。打开同一身份的另一个副本前必须关闭原工作区；
“恢复副本为新项目”仍走 G0002 的 CopyAsNew，生成独立书卷章与修订身份。这两个动作不混用。

## 稿件选择

| 选择 | 正文来源 |
| --- | --- |
| 编辑稿 | 当前保存会话的编辑快照 |
| 工作稿视图 | 每章优先工作指针，否则正式指针；两者均无则拒绝 |
| 正式稿 | 仅正式指针；所选范围有未定稿章则拒绝 |

范围为一起点、首尾包含的章节序号，卷章顺序按作品记录。空正文拒绝；用户可缩小范围。
TXT/Markdown 使用 UTF-8 无 BOM，正文逐字保留，附加书/卷/章标题。Markdown 标题转义常见标记，正文仍是作者原文。
字数只统计正文中的非空白 Unicode Rune；表情按一个 Rune，组合字形不声称等于一个视觉字。

导出对每个选定修订的实际正文重跑当前本书适用规则。报告区分确定性命中、冲突、检测未完成和语义待检；
存在提示时需作者阅读并勾选后才能写入。确认只表示知情导出，不改检查结果、不当作 AI 审校通过。
预览后的正文、规则、稿件选择或范围变化会使写入入口失效；文件选择结束时再复核。

## 模板与秘密

模板 JSON 格式 1 包含一个完整资产的草案、标签、来源和版本，最多读取 20 MB。
导入校验后生成新的模板和版本身份，不覆盖同名/同 ID 源模板。当前 UI 从已发布模板选择入口导出整个资产。
未发布独立草案的专属交换入口留待后续面板完善，不宣称完整库批量导出。

项目备份只包含作品库，模板文件只包含模板资产；不会复制 catalog.db 或 Credentials。
本书连接绑定保留非秘密身份和版本，搬迁后缺少本机连接时明确重绑。Codex 本地路径与 API Key 均不进入作品。
规则表单、规范和修订属于作品内容，随项目备份保留。

## 版本和限制

本阶段未修改作品 schema，沿用 G0006 的 5；旧 1–4 恢复时使用同一已知迁移规则。
没有做 ZIP、Release 或发行升级验收；没有调用模型。备份与导出的本地证据不代替真实 Host 交互验证。
