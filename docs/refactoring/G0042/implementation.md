# G0042 实施说明

日期：2026-09-13。

ReportTemplateInputBuilder 读取完整报告的相关专题、综合结论及疑问。每条保留最多两段有限原文证据，未知问题标为建议，所有输入保留固定来源编号和适用模板维度。

ReportTemplateRequests 先尝试一次转换，不够再按字段及固定顺序分组，组间使用二叉合并。首次发送前固定全部步骤；合并用两个已保存子结果和最小来源身份表，不重复塞入整本小说或全部专题。每次实际发送重新检查系统提示、Schema、输入和输出预留；中文直接进入 JSON，避免 Unicode 转义膨胀。

ReportTemplateConversionService 在独占租约下执行，复用既有模型请求与费用账本。先保存操作 ID 与输入指纹；已有完整且费用明确的响应先本地校验和恢复，未知费用等待显式复核。纠正最多一次，引用具体字段错误并保留成本。取消仍保存成功步骤。

转换库保存失败时写独立恢复文件；两处均失败明确告知未保存，不继续推进。下一次先补检查点，或用现存账本响应补保存。结果和配置冻结，预算只能显式上调。细节见[恢复契约](conversion-recovery-contract.md)。
