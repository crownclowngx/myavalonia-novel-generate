# G0037 实施方案

模型适配器只报告流状态与用量，统一请求服务负责费用和结构校验，分析运行服务负责节点纠正。没有新增通用重试框架。

ModelDiagnostic 使用固定错误分类、白名单字段路径和数值，不回显服务端正文或任意异常文本。流中断、取消时携带已收到用量；完整正文校验失败和未知结束分别记录。

提取提示增加 v4，明确输出结果而非格式定义、数量是上限并给出最小示例。v2/v3 的提示和原契约输入仍可重放。GapOutput 接收可选段号证据，经本地校验转换为 DimensionGap 的来源证据，不放开任意未知字段。

运行每节点持久化 FormatRetries，完整且已知用量的格式错误最多纠正一次，后续阶段额度仍保留。重试前检查其他未复核请求，防止顺便确认未知费用。用户补充约束保留；约束合并超过容量时停止自动纠正。

详细边界见[恢复协议](response-recovery-contract.md)。
