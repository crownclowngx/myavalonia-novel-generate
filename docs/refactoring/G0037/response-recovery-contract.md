# 响应诊断与恢复协议

| 故障 | 恢复行为 |
| --- | --- |
| 格式定义回显、无效 JSON、业务契约失败 | 完整且用量已知时最多一次定向纠正，旧费用保留 |
| 纠正后再次失败 | 暂停并展示字段位置或错误分类 |
| 响应流缺少结束、服务端异常结束 | 保留完整性标志和已收到用量，费用复核后恢复 |
| 请求取消/超时 | 保留候选和已收到用量，不能转换成完整响应 |
| 长度结束 | 独立截断状态；不按格式错误重试 |
| 总额或后续阶段额度不足 | 不自动扩大预算，不发送纠正请求 |

旧记录没有完整性字段时按未证明完整处理，不凭 JSON 看似完整或已有 usage 自动重试。原有用户明确复核入口保留。

只允许外围 BOM/完整代码围栏清理，不从多个 JSON 对象中猜选一个，不给截断字符串补引号。Gaps 可选 Evidence 仍需 1–8 条有效段号；原始候选和其费用不改写。

当前 SSE 单行/单事件 262144 字符、累计 8000000 字符及正文 1000000 字符均为本地防护上限，诊断与远端 token 截断明确区分。
