## 实现边界

本阶段建立实际可读写的来源基础。TXT 解码分章在 G0030，AI 提取在 G0031，运行状态机与节点结果事务在 G0032，报告汇总和 UI 分别在后续阶段实现。只为实际外部存储建立端口，不建立通用 Repository 或任务框架。

来源正文保存解码后的原始换行，不进行规范化，因此证据使用原文本 UTF-16 坐标直接定位。原始字节与解码正文分别保存哈希；在 G0030 导入边界验证编码与正文的对应关系。来源一经导入不可变，重分析不修改来源。
