# G0009 故事记忆与上下文实施计划

基线：`9539b54`（G0008），134 项本地测试通过。关联 [总计划](../../implementation-plan.md#g0009)。

1. G0009-01：建立书内实体/别名、类型化事实候选、证据与来源修订，复用双稿指针投影有效状态。
2. G0009-02：提供有界中文实体/正文检索，不依赖分词器；只查第 N 章之前的有效修订，可从原文重建。
3. G0009-03：建立不可变上下文清单，硬规则和锁定状态必须携带；文风、方法、摘要和证据按明确预算选择。
4. G0009-04：事实候选检查书/章/来源/旧值/证据/锁定项，过期或未知实体不能自动提交。
5. G0009-05：固定中文故事夹具覆盖别名、未来信息、正式与工作稿、放弃、前文变化和重开。

增加原生实体编辑和上下文预览入口；不发起模型生成。作品 schema 升级时保留一致性备份。
保持 SOLID、普通接口与组合、中文注释和专项文档；本地门禁、阶段提交；不使用 AIFLOW、Windows CI 或发布门禁。
