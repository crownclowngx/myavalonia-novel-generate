# 中文检索与来源夹具

固定夹具“雾港来信”：林舟（别名阿舟）在第一章于雾港拾起铜钥匙，后续章的雪原信息作为排除项。
夹具是测试数据，不是真实作者作品或模型质量证据。

| 场景 | 验证结果要求 |
| --- | --- |
| 搜索林舟 / 阿舟 | 两字姓名与别名都命中同一原始修订 |
| 林舟改名林望 | ID、事实键不变，新名能检索旧正文，旧称仍是别名 |
| 第 N 章查询 | 不读取当前章或未来章节，即使未来存在工作修订 |
| 正式 / 工作视图 | 前者排除全部工作稿；后者只接纳当前运行 |
| 放弃工作稿 | 原始历史保留，前文查询与有效事实自然消失 |
| 前文工作稿重排 | 来源指纹过期，装配拒绝使用 |
| 跨书 / 旧值 / 无证据 / 未知实体 | 候选拒绝，不能污染正文修订 |
| 计划或时间不明确 | 不作为已发生事实 |
| 规范在验证后改变 | 工作稿提交及定稿入口再次拒绝 |
| 预算不足 | 硬规则、锁定项、有效事实不能被省略；可选项列出原因 |
| schema 5 升级 | 一致性备份保留原格式，schema 6 默认空实体，不捏造事实 |
| 重开与复制 | 事实、证据、实体引用仍有效，作品身份隔离 |

检索使用有界字面子串，不使用 FTS 分词或向量召回。查询最多 1000 字符，返回 1–50 条（默认 12）。
别名展开最多 256 项，参与扫描的前文正文与摘要总量最多 400 万字符；超出明确停止，不伪装完整召回。
显式关键词可用空格/中英文逗号分隔；默认从当前章纲前 1000 字符取检索材料。别名展开后按命中词数、章序倒序稳定排序。
数据来自修订原文，每次可重建，没有另一份需要双写的索引。对于大量长篇正文，性能/分词增强归 G0019。

`tools/probe-staged-storage.ps1` 已扩展：在干净 Debug 暂存目录的独立 ALC 中加载私有 SQLite 和 win-x64 原生库，
用真实领域规则提交中文工作稿、SQLite 保存重开，再查询林舟/阿舟，均须唯一命中。
这不是 ZIP 发布、Windows CI 或真实 Host 验收。

复跑（仓库根目录，暂存路径须指向本次构建输出）：

```powershell
./tools/probe-staged-storage.ps1 -PluginDirectory <Debug暂存目录>/NovelGeneratePlugin
dotnet test --filter FullyQualifiedName~StoryMemoryTests
```
