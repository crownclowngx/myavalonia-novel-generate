# 全文运行、修订与预算契约

日期：2026-09-13。

| 中断位置或状态 | 恢复行为 | 费用处理 |
| --- | --- | --- |
| 节点已记操作 ID，请求无预留 | 可执行该操作一次 | 尚无远端发送记录 |
| 请求 Reserved/Running，无完整账本 | NeedsAttention，不自动重发 | 沿用预留，不假定免费 |
| 请求 Completed，节点事务未完成 | 重新验证同一完整 JSON，本地提交一次 | 不新增请求 |
| 节点与结果事务完成 | 校验指纹、内容哈希及输出契约后跳过 | 不新增请求 |
| 截断、限流、超时、协议失败 | 保存候选，明确复核后恢复 | 旧计费保留，新操作同一预算 |
| 完整响应缺用量 | 可保存有效结果，后续请求仍被账本阻止 | 缺失计数保持未知 |
| 输入/提示/模型算法版本变化 | 原任务保留；新版本按依赖指纹复用 | 修订继承原预算与总费用 |
| 原文件移动或删除 | 使用已保存快照 | 不需要重新上传/导入原路径 |

覆盖按已完成提取节点的 Body 计算，Context 重叠不重复计数。提取完成态不能用作报告完成态。模型自报完整、摘要文字或请求数量都不能替代范围账本。

预算计数上限 1000；超过预估请求数时在建队列阶段拒绝，不自动拆成多个独立预算。token 预留为输入 UTF-8 字节数、输出上限及适配余量之和，不是精确 tokenizer。提取阶段另持有报告预留；未知费用按原预留计入累计费用。

版本修订保存独立运行 ID、相同预算 ID；缓存只省去有效节点的重复远程调用，不删除旧成本。调整模型或切分仍必须为最终报告和必要修订留出额度。运行锁绑定预算 ID，进程终止自动释放，不通过删锁文件强行抢占。

当前 200 万字符是导入/切分容量验证结果；大量短章可能超过 1000 请求，此类 AI 全流程会明确拒绝并要求重新规划，不能据导入成功宣称 200 万字符真实模型验收通过。
