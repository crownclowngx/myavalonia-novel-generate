# 身份、时序与冲突整合契约

日期：2026-09-13。

| 输入情况 | 本地采纳规则 |
| --- | --- |
| 姓名/别名相同 | 仅作为候选，不直接推定同一身份 |
| 模型确认或推断为同一身份 | 保存成员提及与理由，并保留确定性类型 |
| 模型仍不确定是否同一人 | 保持独立身份、记录可能同一人的成员编号 |
| 同名不同角色或跨批别名 | 保存各自证据，在问题清单标明多个独立身份 |
| 模型漏掉某项提及 | 本地保留未知单例，不能从人物索引消失 |
| 重复归组、引用越界、跨类别合并 | 拒绝整个候选，留在账本等待复核 |
| 倒叙、回忆、梦境或计划 | 保留 Narration 与 StoryTime，章节顺序不自动成为故事时间 |
| 核心规则存在冲突 | 事实矛盾候选标 Uncertain，保留双方事实编号与问题清单 |
| 原始事实未进入整合观察 | 在 UnintegratedFacts 明确列出，原始索引仍完整可查 |

身份批次可能拆开超过 60 项的巨大同名候选集；跨批不会自动再次合并，相关别名/同名歧义进入问题清单。这是当前有界实现的明确限制，不等同于已通过全书人物身份质量验收。

归并输入保留完整事实陈述，实体描述与原文示例按固定上限节选；完整描述和所有证据一直存于下层索引。下一阶段文风分析会按代表性规则回看原句，不仅依赖整合摘要。

每次整合请求的指纹包括来源、冻结连接、提示/契约、选择材料及前置结果哈希。结果只能引用本批已有编号。字段和来源链正确不等于“引用支持结论”，人工语义评阅不得用结构校验通过率代替。
