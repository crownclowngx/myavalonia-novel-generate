## 真实模型证据

实际运行本阶段 `ModelRequestService → CodexTextModel → CodexProcess`，使用本机已登录 CLI 0.153.4、
`gpt-6-astra`、low、输出软目标 2048，单次预算 100000 tokens/1 请求，超时 3 分钟。
样本只要求一句不超过 30 字的雨夜书店描写；没有发送个人小说或密钥。
返回：“雨夜，书店打烊前，那个失踪三年的客人推门而入。”
成功请求用量：输入 9166、输出 56，总计 9222 tokens；这不是套餐剩余额度。
记录在 `artifacts/G0008/live-probe/bin/Debug/net10.0/result.json`，探测程序与原始本地账本在同目录树。

成功前有四次 CLI 诊断解析提前停止，均保留未确认用量的账本，不按零计费；没有自动重试。
查明原因是关闭 Code Mode 宿主时的启动 error 项，之后区分诊断与真正工具事件并保持执行能力关闭，才成功完成文本请求。
