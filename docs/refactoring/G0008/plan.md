# G0008 模型访问与用量边界实施计划

基线：`3624a94`（G0007），99 项本地测试通过。关联 [总计划](../../implementation-plan.md#g0008)。

## 实施步骤

1. G0008-01：核对官方协议与本机 Codex CLI 能力，分别记录套餐、API 用量及输出限制。
2. G0008-02：实现窄文本适配器，解析 SSE / JSONL，分离推理，限制输入、事件和输出大小，验证结构化候选。
3. G0008-03：请求发送前持久化预算预留；流式片段先入账再通知 UI；失败、取消、截断保留候选，未知用量不能归零，不自动重发。
4. G0008-04：按冻结连接读取当前凭据；HTTP 禁用重定向；增加用户主动触发的小样本连接检测及取消。
5. G0008-05：本地协议、故障、预算和界面命令测试；使用既有 Codex 登录与 GPT-6 做有限真实验证。

## 设计与验证约束

遵循 SOLID：应用服务管理请求生命周期和预算，适配器只处理协议，持久化实现不参与提示词生成。使用普通接口与组合，不引入通用代理框架。注释和专项文档使用中文。

常规测试不使用远程服务或密钥。真实检测与离线凭据状态分开；启动不请求模型。不使用 AIFLOW、Windows CI 或发布门禁。DeepSeek 无有效测试密钥时，以官方契约和 Fake HTTP 验证并明确标记未实测。
