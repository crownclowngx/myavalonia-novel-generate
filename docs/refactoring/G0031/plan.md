# G0031 阶段计划

日期：2026-09-12。状态：阶段已验收，见[结果](result.md)。基线：`1dcbd90`，313 项本地测试通过。

实现 G0031-01–05：六维结构化提取契约、冻结连接与请求账本复用、精确来源证据验证、有界输出失败处理和受控/真实小样。实际模型按用户要求使用 DeepSeek Flash；一次性密钥仅在实测进程内存中使用。

模型输入分为带编号的原文段落。v1 实测发现抄写引文会改动原字，当前 v2 响应只引用段号，由本地取回原文及 UTF-16 坐标，避免让模型抄写或猜字符位置。实体提及与维度观察分开，保留叙述来源和时间线索。模型只产生候选，完整覆盖仍由运行账本计算。

初始小样为 2 次请求、150,000 保守预留 token、8192 输出、low 思考。因实际空截断与引文问题，2026-09-13 明确扩展为累计最多 8 次生成请求、500,000 保守预留 token（含历史失败和协议探针），属于本次 80 次/3,000,000 总预算内；当前提取采用 16384 输出、关闭思考。费用和已知/未知用量单独记录。此步骤不运行整本调度，运行与缓存属于 G0032。
