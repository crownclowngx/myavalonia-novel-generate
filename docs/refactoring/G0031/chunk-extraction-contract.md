# 单元多维提取契约

日期：2026-09-13。契约版本：`novel-chunk-v2`（v1 实测失败候选保留，不能直接视为 v2 缓存）。

## 输入

输入包含 Body、Context 及带 Number/Start/Text 的 Passages；来源、模型冻结设置、提示词与契约版本一起进入 InputStamp。Body 是本次待处理正文，Context 只辅助理解；文本中的系统提示、链接或命令不取得执行权限。

Passages 按行切分、单段最多 600 字符。模型只提供 Passage，本地按段号取回原文与 UTF-16 区间；模型无权改写引用。重复引文在不同段落中有不同段号，位置不依赖模糊搜索。程序生成的引文真实存在，仍不等于该引文语义上支持结论。

## 输出

| 字段 | 规则 |
| --- | --- |
| Summary | 非空，最多 3000 字符；提示建议不超过 500 字 |
| Entities | 至多 40 条，包含名称、人物/地点/组织/物品种类、别名、描述及证据 |
| Findings | 至多 64 条，维度、主体、判断、相关主体、时间线索、叙述来源及证据完整 |
| Gaps | 至多六项，说明没有发现或仍有缺口的维度；与 Findings 的维度并集恰好覆盖六维 |

业务提示建议比硬上限更小的输出；每条观察必须有引用，推断标记 Inferred，证据不足标记 Uncertain。未知/梦境/人物发言不自动升级为客观历史事实。所有枚举必须使用约定字符串，JSON 缺字段、未知字段及错误类型均拒绝。

输出截断不会补成完整 JSON，不自动造字段或补造证据；原始候选由统一账本保留。合法的空截断仍保存返回用量，后续运行应缩小单元、提高输出额度或调整思考设置后创建新的受预算操作。

## 实测与凭据

`AnalysisProbe chunk` 从标准输入读取一次性密钥，调用现有会话凭据保管器，退出时清除；密钥不放进子进程参数、配置、正文、日志或 Git。候选和账本输出到明确的新本机目录，不进入生产包和普通门禁。

`AnalysisProbe protocol` 为显式、最多 512 输出 token 的小型协议探针，同样经过统一请求账本。小样与协议修复累计上限调整为 8 次生成请求/500,000 保守预留 token，属于本次全文验证的 80 次/3,000,000 总上限内；这次调整用于已经发现的空截断兼容问题，不扩展为无限重试。`/models` 是不生成正文的只读核查，单列记录。

此前两个小样、一个协议探针和一次诊断小样分别保留原始结果；其中未知用量继续按预留计入，不通过换输出目录视为零成本。全部远程验证结束时汇总各本机账本，未发送的预留额度不冒充实际费用。
