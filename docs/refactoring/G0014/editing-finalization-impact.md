# 改稿、连续定稿与影响契约

## 作者操作

1. 在正文手写，或选中文字后填写改写要求；续写固定追加到末尾。改写/续写消耗最多两次模型请求，不追加自动修正。
2. 候选与正文分开显示，差异展示公共前后缀之间的完整区间；原生 UTF-16 选区不能拆开一个字符。
3. 仅复核当前正文消耗一次检查请求，重建摘要和事实；字数采用单章区域目标的 ±20% 门禁。
4. 通过后明确提交工作稿。正文、摘要、事实、父修订一起保存；任务期间新输入或规范/修订变化使旧候选失效。
5. 放弃当前候选只停止采用，任务恢复记录保留。历史修订可与编辑稿比较；已有整轮放弃和从本章回退继续保留全部历史。
6. 逐章审阅后填写连续范围并勾选确认，明确执行整批定稿；缺章或失效不留下半批正式稿。

## 保守影响

编辑稿变化、当前 Passed 审校规范变化或前文修订变化，均在清单标出本章及后续章。
不会自动改正式正文或覆盖旧摘要。存在后续工作稿时，需先明确放弃本轮工作稿；正式稿需先回退本章及后续，
然后保存当前章纲并逐章复核、提交和重新定稿。首版保守处理依赖，精细影响范围留到 G0017。

旧版审校缺少全报告规范证明时显示过期；旧历史仍可阅读、备份和明确选版导出。
导出提示按实际所选修订计算，仅有编辑缓冲变化不会撤销原正式稿的审校结论；规范升级则会提示所选稿及依赖前文待复核。
规则例外继续保存在版本化规则的作者、原因和来源中；导出预览是本地检查，确认提示不冒充新的 AI 审校。

## 能力边界

差异不是通用多段 diff 或自动合并；AI 建议不自动成为正式稿。复核与改写仍要求本章章纲有效和前文依赖处理完毕。
模型报告是辅助意见，本地证据门禁、作者确认和文学质量判断各自独立。
