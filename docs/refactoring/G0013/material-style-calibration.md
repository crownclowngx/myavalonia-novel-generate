# 短材料方法化与文风校准契约

## 可操作路径

在共享创作模板库展开材料区域，粘贴或输入 TXT/Markdown 文件路径，选择用途、来源、处理长度和独立连接。
保存并提炼后可编辑方法/文风文本，点击证据条目定位原文。输入试写剧情与每行一条事实约束，可生成章纲小样与 A/B 对比。
作者选择、修改、批注或跳过试写；选择不会自动发布或修改作品。

采用到本书：回到作品的本书规范区域，刷新已提炼材料并明确采用；本书规范独立保存，原有世界与长期规则保留。
采用会使依赖旧规范的章纲或候选需要重新核对，不能自动重写正式稿。
另存共享模板：材料面板点击保存为命名模板，创建 v1；已采用旧规范的书不随之改变。

## 证据与限制

全文上限 20000 字符，单次处理上限 12000 字符，分段坐标按 .NET 字符串偏移记录；未处理部分不声称完成分析。
每张卡片 1–6 个引用，必须属于已处理段的连续原文，近义字替换也不算逐字证据。推断保留原样本依据并明确标记。
卡片数量、单字段及渲染总长度都有门禁。模型可能引用错误，失败保留请求原始输出和用量，不自动重试。

对比试写按同一剧情和事实约束生成；报告引用必须能在 A/B 中定位，但不能据此证明所有语义和文学质量。
已提供方法时，小样必须逐字引用当前方法文本。作者改了剧情、事实或规范后，旧试写标记为依据变化，不能冒充新版本样稿。
试写正文不会被放入模板或小说正文，只保存作者选择与批注。材料来源更新后，旧提炼不能直接采用，需重新分析。

材料与候选存储属于本机；本书 MaterialSources 保存采用时的名称、来源、版本、方法/文风、作者反馈与选择，因此书籍移走后仍保留已采用依据。
材料库当前只列最近 100 项，无删除/归档和长材料批处理；完整参考小说、PDF/PPT/OCR 不在本阶段。

## 费用与生命周期

提炼与试写各用独立 250000 token 预算、最多一条请求，仍受连接串行与统一凭据核对约束。输入 UTF-8 预留不是精确 tokenizer。
草案输入不调用模型；点击分析/试写才发生远程请求。隐藏 Tool 不取消，关闭作品不影响独立材料任务；关闭 Tool/Host 取消并保存草案。
并发保存失败不自动合并覆盖，保留作者表单供复核。需放弃本地更改时有明确重新读取按钮。
