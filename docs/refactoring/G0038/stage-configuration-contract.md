# 分阶段配置与结果复用

| 阶段 | DeepSeek 默认思考 | 单次输出起点 |
| --- | --- | --- |
| 全文提取 | none | 16384 |
| 跨章整合 | high | 32768 |
| 分层汇总 | none | 16384 |
| 专题分析 | high | 32768 |
| 综合结论 | high | 32768 |

默认模型沿用所选连接的检查模型。Codex 默认沿用原检查参数，不注入不支持的 none/max。配置值是工程调优起点，不承诺所有文本均可在该额度完成。

重新读取运行时展示该运行设置；新建修订才采用编辑后的参数。普通继续保持已冻结配置。成功节点在修订中沿用原配置和缓存，来源切分变化使相关提取及下游重新计算。累计预算和历史失败成本不清零。

运行库版本升级到 2，防止旧程序忽略节点配置。升级前使用 SQLite Backup API 在本机工作区 Backups 下建立 schema1 快照；备份失败阻止升级，未来版本及外来数据库拒绝写入。回退旧插件前需恢复匹配的数据库备份，不直接打开新版运行库。
