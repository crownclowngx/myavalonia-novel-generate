## 启动和建立作品

```powershell
dotnet run --project src/NovelGeneratePlugin.Standalone -c Debug
```

独立窗口使用同一份插件代码，适合本地创作与开发预览。真实 Host 中打开“小说创作” Document；共享工具为“创作模板库”和“模型连接”。
本机已部署的 1.2.0 可通过“从报告生成模板”自动保存独立草案，再编辑并保存版本供作品采用。分析与转换均保留在本机，失败先查看历史和费用再继续；操作见[手册第 9 节](product/novel-workbench-user-manual.md#9-整本小说分析从-txt-到综合报告)及[本次导入指引](deployments/2026-09-13-report-template.md#如何导入和采用)，实施状态见[改造进度](novel-analysis-template-conversion-plan.md#progress)。
填写书名和创意，创建新的 `.noveldb`。目录可新增卷/章，正文输入自动保存；底部分别显示稿件、任务和保存状态。
打开已有作品不依赖网络或密钥。保存失败先查看恢复提示，不删除原库及迁移前备份。

## 配置 Codex 套餐

1.0.1 新连接现在默认 DeepSeek：地址、三类任务模型 `deepseek-flash`、推理 `high` 和输出上限 `65536` 已填好，输入 API Key 后点击“保存连接（配置与 Key）”。需要跨重启使用时勾选 Windows 加密保存；具体步骤见 [DeepSeek 默认参数说明](deepseek-defaults.md)。下面继续说明如何切换到 Codex 套餐。

1. 在“模型连接” Tool 新建连接，Provider 选择 Codex 套餐，填写本机已登录的 Codex CLI 完整 exe 路径。
2. 规划、正文、检查均可填 `gpt-6-astra`；本次实测为输出上限 8192、推理强度 low。CLI 0.153.4 已实测；当前机器的旧全局 CLI 0.140.0 未通过该模型调用。
3. 点击“仅保存配置”后可生成一句检测，此动作消耗套餐额度。查看实际用量；未知用量不会自动当成零。
4. 在本书“设定 → 本书模型连接”刷新并明确绑定。共享连接更改后要重新绑定，本书不会静默切模型。

使用既有 Codex 登录，不复制认证文件，也不把套餐登录转换成 API Key。DeepSeek 单独使用 HTTPS 端点与独立 Key，
协议和配置见 [G0008 模型接入](refactoring/G0008/implementation.md)，不影响本书的 Codex 验证路径。

## 从章纲到工作稿

在“设定”采用本书规范/模板；在“创作”填写主线、卷目标和章纲后保存有效版本，或选择自动/协作规划。
材料工具可接收短文本/TXT/Markdown，提炼方法、文风、A/B 试写，作者修改后再明确采用。

单章区域设置目标字数和修正次数。生成结果先显示为候选，审校通过后可明确提交。
连续创作设置 3–5 章及总请求/token 上限；正常通过的章节自动存为工作稿，不逐章等待确认。
“章后暂停”完成本章事务后停止；“立即取消”取消当前请求。恢复先读取记录、核对失败或未知用量，再明确继续。

## 改稿、定稿与导出

正文选区改写和末尾续写在单章区域发起，候选与原文并列比较。仅复核当前正文可重建摘要和事实。
接受候选前会核对正文、父修订和规范；迟到候选不能覆盖后续人工修改。

“检查 → 本章提纲与修订”可查看历史、影响清单、整轮放弃和回退。修改前文后先处理后续工作稿/正式稿依赖，再按顺序复核。
逐章审阅并勾选确认后，可对连续范围一次定稿。保存不等于定稿，未检查也不等于 AI 检查通过。

“项目 → 备份与正文导出”明确选编辑稿、工作稿视图或正式稿，以及 TXT/Markdown、起止章；先预览检查，再确认提示并写入新文件。
现有目标文件不会被覆盖。备份使用一致性 SQLite 快照，可恢复到新文件；数据库不携带明文 Key。
